# Deferred and delayed scope

Aligned with [RELEASE_PRIORITIES.md](RELEASE_PRIORITIES.md).

## Shortly after launch (post-Must train)

Do not block store launch on these, but schedule soon after:

- Multiple memorials (Premium) — early UI may already exist; finish packaging/polish
- Voice transcription (private; never clones a loved one’s voice)
- Complete keepsake builder
- Family Circle (invite trusted people; Owner / Contributor / Viewer; approval queue)
- Gift subscriptions (store non-renewing year + durable redeem)
- Relationship-based prompt packs
- Import from existing PDF journal
- Home-screen quick-memory widget (native)

### Family Circle detail (when scheduled)

- Invite trusted people into a private memorial
- Roles: Owner, Contributor, Viewer
- Owner approval queue before contributions appear in the keepsake
- Contribution types: stories, photos, recipes, voice, interview answers, milestones
- Conflict handling for concurrent edits

### Optional memory helpers (not counseling)

When AI-assisted helpers ship, only the safe list in [AI_STANCE.md](AI_STANCE.md):

- Private audio transcription
- Spelling correction chosen by the user
- Sorting / locating entries
- Detecting duplicate uploads
- Building an export index
- Suggesting titles from the user’s own text

## Delay / far horizon

- Expanded media storage, tablet layouts, richer export themes
- Print partner / printed-book ordering **inside the app**
- Complex page decoration and large sticker editor
- Extensive daily content

## Explicitly out (or until legal/product review)

Matches the **Delay** list and hard product bars:

- Public community
- Social sharing feed
- Public profiles, likes, comments
- AI emotional advice / grief counseling / healing-tool frameworks
- Grief tracking, grief scores, emotional scores
- Therapy/clinical diagnosis or treatment claims
- Advertising or sale of journal content
- Automatic Etsy → app entitlement without store policy review
- Deceased impersonation or generated voice replicas
